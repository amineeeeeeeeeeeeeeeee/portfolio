Todo Applicatie

Project beschrijving

Een gebruiksvriendelijke takenlijst applicatie waarmee gebruikers taken kunnen toevoegen, bewerken, voltooien en verwijderen. De app slaat alle gegevens lokaal op zodat taken behouden blijven na het sluiten van de browser.

Uitdagingen en oplossingen

Het beheren van de applicatiestatus en het synchroon houden van de UI met de data was de grootste uitdaging. Ik heb gekozen voor React met hooks om een efficiënte state management te realiseren.

Functionaliteiten

  • CRUD operaties (Create, Read, Update, Delete)
  • Filteren op actieve/voltooide taken
  • Zoekfunctionaliteit in taaklijst
  • Prioriteitsindicatie (hoog/midden/laag)
  • Deadline datum toevoegen
  • Dark mode toggle
  • Data persistentie met localStorage

Geleerde lessen

Door dit project heb ik de kracht van React en component-gebaseerd denken ervaren. Ik heb ook geleerd hoe belangrijk een goede gebruikerservaring is, zelfs voor eenvoudige applicaties zoals een todo-lijst.

Technologieën

  • React.js
  • JavaScript (ES6+)
  • CSS Modules
  • LocalStorage API
  • React Hooks (useState, useEffect)
