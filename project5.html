Weather App

Project beschrijving

Een weersvoorspellingsapplicatie die actuele weergegevens en 5-daagse voorspellingen toont voor elke locatie wereldwijd. De app gebruikt een externe weer-API en toont informatie zoals temperatuur, luchtvochtigheid, windsnelheid en weersomstandigheden.

Uitdagingen en oplossingen

Werken met externe APIs en het correct afhandelen van asynchronous requests was de grootste uitdaging. Ik heb async/await en fetch API gebruikt voor het ophalen van data, met goede error handling voor API-limieten en netwerkproblemen.

Functionaliteiten

  • Zoeken op stadsnaam of postcode
  • Auto-detectie van huidige locatie (geolocatie)
  • 5-daagse weersvoorspelling
  • Weersicons die passen bij de condities
  • Extra info: luchtvochtigheid, windkracht, UV-index
  • Favoriete locaties opslaan
  • Celcius/Fahrenheit toggle

Geleerde lessen

Dit project heeft me veel geleerd over API-integratie, asynchronous JavaScript en het omgaan met gebruikerslocatie. Ook heb ik geleerd hoe ik een applicatie robuust kan maken met goede error handling.

Technologieën

  • JavaScript (ES6+)
  • OpenWeatherMap API
  • Fetch API / Async/Await
  • Geolocation API
  • HTML5 / CSS3
