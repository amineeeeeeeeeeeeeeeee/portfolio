E-commerce Website

Project beschrijving

Een volledig functionele e-commerce webapplicatie waarmee gebruikers producten kunnen bekijken, toevoegen aan een winkelwagen en bestellingen kunnen plaatsen. De website bevat een dynamisch productoverzicht, zoekfunctionaliteit en een gebruiksvriendelijk afrekenproces.

Uitdagingen & oplossingen

Een van de grootste uitdagingen was het implementeren van een real-time winkelwagen die updates opslaat zonder de pagina te verversen. Dit heb ik opgelost met JavaScript en localStorage, waardoor de winkelwagenstatus behouden blijft, zelfs na het sluiten van de browser.

Functionaliteiten

  • Productcatalogus met filteropties (categorie, prijs, beoordeling)
  • Zoekbalk met autocomplete suggesties
  • Dynamische winkelwagen met hoeveelheidsaanpassing
  • Checkout systeem met formuliervalidatie
  • Responsive design voor alle schermformaten
  • Productdetailpagina's met afbeeldingengalerij

Geleerde lessen

Tijdens dit project heb ik veel geleerd over DOM-manipulatie, event handling en het beheren van applicatiestatus in pure JavaScript. Ook heb ik ervaring opgedaan met het ontwerpen van een intuïtieve gebruikersinterface.

Technologieën

  • HTML5
  • CSS3 / Flexbox & Grid
  • JavaScript (ES6+)
  • Bootstrap 5
  • LocalStorage API
